VERSION: 5.0.9
DETAILS:

new: Browse pinned folders beside the dock in Grid, List or a curved Fan layout; double-click opens files or enters subfolders, Back / Command-Up stops at the pinned folder, drags to and from Finder always copy
new: Per-folder view options (click behavior, layout, icon size, grid columns, grid names, hidden files, sort, reverse order, folders first) saved per folder and imported from ExtraDock 4
new: App Stack file browser with multi-select, keyboard navigation, native context-menu actions (Open / Open With, Get Info, Quick Look, Share, Tags, Copy Path, Rename, Duplicate, Compress, Copy / Cut / Paste, Move to Trash) and group drags; existing files are never silently replaced
new: App Stack grid size from 3x3 to 8x8 per stack; large folders scroll instead of clipping
new: Monitor Dock preset in the Manager's Items plus menu adds CPU, Memory, GPU, Battery, IP Address and Bluetooth Battery in one click
new: IP widget shows public and/or local addresses for one or more adapters; a disconnected adapter shows as disconnected; Copy only copies a valid address
new: App Connections (Settings > Integrations) lets DockFlow show, hide or toggle docks through the Talk SDK after an explicit, code-verified pairing with per-permission consent; DockFlow can open the request with permissions pre-ticked; disabled docks are listed too
new: Export Performance Diagnostics (Settings > Diagnostics) records ten seconds of ExtraDock's own CPU, memory, wakeups and disk activity plus power, thermal and anonymous dock context and the last 15 minutes of performance logs; saved locally, nothing uploaded
improved: Native Dock spacers appear as gaps in the Live Dock and follow changes live; Native Dock Copy imports folder/file-section spacers as Spacer widgets
improved: Saved App Stack names show in the Manager's items list and the dock hover label
improved: Log exports report the actual first and last timestamps they contain
bug fix: DockFlow preset switches during a native Dock restart are retried every 200 ms for about three seconds instead of being dropped as unavailable
