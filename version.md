VERSION: 5.2.5
DETAILS:

new: Notch dock backgrounds: Style → Background lets a notch dock be Black, any Color, Blur or Liquid Glass (still marked Beta on macOS 27). Thanks to David and Akiva for asking
new: Hide docks from screen sharing: Settings → Behavior → Privacy keeps your docks out of Zoom, Meet and Teams shares, recordings and screenshots, while they stay on your screen
new: A new color picker: Every color setting opens a small picker right next to it instead of the macOS Colors window, with a palette, your recent colors, a Custom tab, a hex field and an eyedropper. The Battery, Bluetooth and Clock widgets use it too, and your saved colors stay the same
new: One shortcut for several docks: Give docks the same Show/Hide shortcut and one press shows or hides them all together
new: Label widget: A free widget that names a group of icons with a title, an optional second line and a length you choose, with vertical text for side docks
new: Tint icons: Style → Icons → Tint icons colors every app, file and folder icon in a dock in one color
new: Always show item names: Style → Size & Spacing shows every item's name without hovering
new: Hide a dock item for a while: Click the eye button in Manager → Items to hide an item without removing it. It comes back in the same place
new: One setting for every folder: Settings → Behavior → Clicking a folder picks Browse beside dock or Open in Finder for all folders at once
new: App Stack single click: A new App Stack setting opens apps and folders with one click
new: Shelf after dragging out: Shelf and Shelf (Cloud) can keep an item or remove it once you drop it somewhere else
improved: Safer Move to Trash: In App Stacks and the folder browser it sits alone at the bottom, always asks first, and can be hidden in Settings → Behavior
improved: Folder browser closes like the macOS Dock: A click in another app, on the desktop or in the menu bar closes it
improved: The same folder twice: Add a folder again so one copy opens in Finder and the other browses beside the dock
improved: Drag widgets from the Widgets Library: Dropping a widget card from the Manager onto a dock adds it there
improved: No duplicate Shelf items: Dropping a Shelf item back onto its own Shelf is refused. Dropping it on the other Shelf adds it once
improved: Manager window always fits: Its content no longer gets cut off or pushed under the title bar
improved: Ready for macOS 27: ExtraDock uses the new "Device Control and Data Access" name for Accessibility on macOS 27
bug fix: Drop files on your dock apps: Drag a file from the Shelf or File Shelf panel, the Screenshots gallery or the Trash popover onto an app in a dock and it opens in that app, instead of landing on the Desktop
bug fix: File Shelf keeps files you didn't drop: With Remove after drag out, cancelling a drag (Escape) or dropping where nothing accepts it no longer removes the file. With Ask every time, ExtraDock asks after the file has landed, not the moment you start dragging
bug fix: File Shelf shows the real file: Files dropped on a File Shelf tile show their real name instead of a "Missing" card
bug fix: Deleted apps leave the Live Dock: Apps you deleted no longer show up in a Live Dock as blank white icons. Thanks to Brandon for the report
bug fix: Folders keep their click choice: Exporting and importing a dock keeps each folder's click setting again
